# Dotfiles

Setup script for macOS, Debian, or Ubuntu, configured to use Fish as the
default shell, with FZF, command-line search tools, Oh My Fish, Fisher, Neovim
with AstroNvim, and Nano syntax highlighting and settings.

## Install

Run the script as your normal user (not with `sudo`). It uses `sudo` for system
packages and login-shell changes:

```bash
./setup.sh
```

The installer prompts for `sudo` access and changes your login shell to Fish.
Log out and back in for the new login shell to take effect.

On macOS, install the Xcode Command Line Tools first (`xcode-select --install`).
The script installs Homebrew if it is missing and uses it for all packages.

System packages live in `packages/`. `setup.sh` runs `packages/install.sh`,
which installs `packages/Brewfile` with `brew bundle` on macOS and the apt
packages and Neovim release build on Debian and Ubuntu. To install or update
only the packages:

```bash
./packages/install.sh
# or, on macOS:
brew bundle --file packages/Brewfile
```

Add macOS packages by editing `packages/Brewfile`.

## What it installs

- Fish, set as the default login shell
- `fd`, `bat`, `hexyl`, The Silver Searcher (`ag`), `exa` (`eza` on macOS),
  FZF, ripgrep, Nano, curl, git, and Python 3
- Podman and Tailscale
- Neovim (0.11+) with the [AstroNvim](https://astronvim.com) starter template
  in `~/.config/nvim`, plus its helpers: lazygit, gdu, bottom, and a C compiler.
  On Debian and Ubuntu, Neovim comes from the official release build in
  `~/.local/opt/nvim`, because the distribution packages are too old; lazygit,
  gdu, and bottom are installed only when the release packages them
- JetBrains Mono Nerd Font (macOS only) for AstroNvim icons
- `nvm.fish` via Fisher, configured to install and use the latest Node.js
- `ryotako/fish-completion-generator` completions for installed command-line
  tools and `PatrickF1/fzf.fish` for FZF-powered Fish key bindings (`Ctrl-T`
  for directory search, `Ctrl-R` for history, and `Ctrl-V` for variables)
- Kilo Code CLI (`@kilocode/cli`) and OpenCode CLI (`@opencode-ai/cli`),
  installed through npm into `~/.local` without system-wide global packages;
  the commands are `kilo` and `opencode`
- Fisher and Oh My Fish
- FZF Fish configuration in
  `~/.config/fish/conf.d/dotfiles-setup.fish`
- The `pyclean` Fish function in `~/.config/fish/functions/pyclean.fish`
- The `envpick` Fish function in `~/.config/fish/functions/envpick.fish` for
  searching exported variables and printing, editing, or deleting them for the
  current session
- The `ai` Fish function for streaming chat with an OpenAI-compatible API
- Nano syntax highlighting and settings in `~/.nanorc`

Nano configuration is appended only once; the FZF configuration file is
generated by the installer. AstroNvim is skipped if `~/.config/nvim` already
exists; move it aside and rerun to install it. Old Neovim data, state, and
cache directories are backed up with a timestamp suffix before installing.

### macOS notes

- Set your terminal font to "JetBrainsMono Nerd Font". Terminal.app lacks true
  color, so use iTerm2, WezTerm, Kitty, or Ghostty for AstroNvim's theme.
- Run `podman machine init && podman machine start` before using Podman.
- Run `sudo brew services start tailscale`, then `tailscale up`.

## AI chat

Start `ai` in Fish. On first use, it prompts for the API base URL, model, and
API key; the defaults target OpenAI. The API key is read without echo and is
used for that chat only. For repeated use, export `AI_BASE_URL`, `AI_MODEL`,
and `AI_API_KEY` in your Fish configuration. Local endpoints can leave the key
blank. The chat keeps conversation context until `/clear` and exits with `/exit`
or Ctrl-D. The endpoint must support the OpenAI-compatible streaming
`/chat/completions` API.
