# Dotfiles

Setup for macOS, Debian, and Ubuntu: Fish as the login shell, Neovim with
AstroNvim, modern command-line tools, and on macOS a full Homebrew setup of
CLI tools, developer tools, apps, and fonts.

## Install

Run the installer as your normal user (not with `sudo`). It asks for your
`sudo` password when it installs system packages and changes your login shell.

On macOS, install the Xcode Command Line Tools first:

```bash
xcode-select --install
```

Install without cloning the repository:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/imnotdev25/dotfiles/HEAD/setup.sh)"
```

The script downloads the rest of the repository to a temporary directory,
installs from it, and removes it when done. Set `DOTFILES_REPO=owner/repo` to
install from a fork.

Or install from a clone:

```bash
git clone https://github.com/imnotdev25/dotfiles.git
cd dotfiles
./setup.sh
```

Log out and back in afterwards so Fish becomes your login shell.

## Repository layout

```text
setup.sh             Main installer: packages, Fish, AstroNvim, Nano
packages/install.sh  System packages (Homebrew on macOS, apt on Debian/Ubuntu)
packages/Brewfile    macOS packages, installed with brew bundle
fish/functions/      Fish functions (ai, envpick, pyclean)
scripts/ai-chat.py   Streaming chat client used by the ai function
```

To install or update only the system packages:

```bash
./packages/install.sh
# or, on macOS:
brew bundle --file packages/Brewfile
```

Add or remove macOS packages by editing `packages/Brewfile`.

## What it installs

### On every system

- Fish, set as the default login shell, with Fisher and Oh My Fish
- `PatrickF1/fzf.fish` key bindings (`Ctrl-T` directories, `Ctrl-R` history,
  `Ctrl-V` variables) and completions generated by
  `ryotako/fish-completion-generator`
- `nvm.fish` with the latest Node.js
- Kilo Code CLI (`kilo`) and OpenCode CLI (`opencode`), installed through npm
  into `~/.local`
- Neovim 0.11+ with the [AstroNvim](https://astronvim.com) starter template in
  `~/.config/nvim`, plus lazygit, gdu, bottom, and a C compiler
- fd, ripgrep, The Silver Searcher (`ag`), fzf, bat, hexyl, git, curl,
  Python 3, Nano, Podman, and Tailscale
- Fish functions: `ai` (AI chat), `envpick` (search, print, edit, or delete
  exported variables in the current session), and `pyclean` (remove Python
  caches)
- Nano syntax highlighting and settings in `~/.nanorc`

### macOS (`packages/Brewfile`)

- CLI essentials: stow, topgrade, tmux, herdr, taproom
- CLI basics: eza, zoxide, yazi, superfile, sd, jq, just, ouch, ast-grep, ack,
  coreutils, rsync, csvlens, most, grc, mas, duti, chafa, vhs, exiftool, kage
- Images: imagemagick, graphicsmagick, jpegoptim, mozjpeg, optipng,
  ffmpegthumbnailer
- Monitoring: btop, procs, dua-cli, duf, ctop
- Productivity: rclone, mole, todo-txt, tuxedo, tealdeer, fastfetch, figlet
- Languages: Go, Lua and LuaRocks, Bun, Deno, fnm, fakedata
- DevOps: docker, k9s, Apple `container`, OrbStack, doctl, s3cmd, httpie,
  curlie, monolith, tectonic, ghostscript
- Git: gh, git-delta, git-extras, git-lfs, tig, tuicr, GitButler
- Dev utilities: lazydocker, miniserve, scc, watchexec, wget, atac, hyperfine
- Network and security: nmap, bettercap, Wireshark, termshark, socat, mkcert,
  dnsmasq, nginx, mosh, moshi-hook, sshs, boring, ssh-copy-id, GnuPG,
  GPG Suite, age, openssl, nss, clamav, lynis
- Apps: Google Drive, Tailscale, TigerVNC, FluidVoice, Choosy, Cyberduck,
  Obsidian, Sequel Ace, Markdown Preview
- Fonts: SF Pro, SF Symbols, Inter, Lilex, JetBrains Mono, and Nerd Fonts
  (JetBrains Mono, Lilex, Fira Code, Symbols Only)
- Quick Look plugins: QLMarkdown and QuickLook Video

Several Quick Look plugins (QLColorCode, QLStephen, QuickLook CSV/JSON, and
others) are commented out in the Brewfile because Homebrew has disabled them.

### Debian and Ubuntu

Packages come from apt. Neovim is installed from the official release build in
`~/.local/opt/nvim`, because the distribution packages are too old for
AstroNvim. lazygit, gdu, and bottom are installed only when your release
packages them. `exa` is used instead of `eza`.

## Notes

- AstroNvim is skipped if `~/.config/nvim` already exists. Move it aside and
  rerun to install it. Existing Neovim data, state, and cache directories are
  backed up with a timestamp suffix first.
- The Nano settings are appended to `~/.nanorc` only once. The Fish settings
  in `~/.config/fish/conf.d/dotfiles-setup.fish` are regenerated on each run.
- On macOS, `gdu` is linked to Homebrew's `gdu-go`, because coreutils also
  installs a `gdu` (GNU du).

### After installing on macOS

- Set your terminal font to "JetBrainsMono Nerd Font". Terminal.app lacks true
  color, so use iTerm2, WezTerm, Kitty, or Ghostty for AstroNvim's theme.
- Run `podman machine init && podman machine start` before using Podman.
- Connect Tailscale with the Tailscale app, or run
  `sudo brew services start tailscale` and then `tailscale up`. Run only one
  of them.
- The first `brew bundle` run takes a while. GPG Suite and Wireshark ask for
  your password during installation.

## AI chat

Start `ai` in Fish. On first use, it prompts for the API base URL, model, and
API key; the defaults target OpenAI. The API key is read without echo and is
used for that chat only. For repeated use, export `AI_BASE_URL`, `AI_MODEL`,
and `AI_API_KEY` in your Fish configuration. Local endpoints can leave the key
blank. The chat keeps conversation context until `/clear` and exits with
`/exit` or Ctrl-D. The endpoint must support the OpenAI-compatible streaming
`/chat/completions` API.
